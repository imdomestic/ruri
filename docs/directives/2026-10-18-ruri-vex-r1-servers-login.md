# 执行指令补充：ruri R1 改为多服务器加登录

- 日期：2026-10-18
- 补充对象：`2026-10-17-ruri-vex-experimental.md`（R1）
- 依赖：vex 仓库的 `2026-10-18-vex-p1-login.md`。服务端没有提供邀请接口之前，登录部分不能做真实联测，不要用 mock 代替。

本补充与 R1 原指令冲突的地方，以本补充为准。

## 背景

- 一个用户可能同时使用多个部署者的 vexd，所以客户端要支持多台服务器。
- 现在的「Vex token」输入框让人看不懂，改为明确的登录流程。GUI 中不再出现 token。

## 设置界面

```
实验性功能
  [启用 Vex]                                       ●
  连接自托管的 Vex 服务器，浏览项目并进入模组预览房间。

  Vex 服务器
  ┌───────────────────────────────────────────────┐
  │ encore              已登录：linwhite      ⋯   │
  │ encore.inner.imdomestic.com:8791               │
  ├───────────────────────────────────────────────┤
  │ friend-vex          未登录          [登录] ⋯   │
  └───────────────────────────────────────────────┘
  [＋ 添加服务器]
```

- **服务器行**：
  - 名称取 `/v2/meta` 返回的 `name`，用户可以改名；名称下方显示地址。
  - 状态有四种：已登录：<用户名>、未登录、无法连接、登录已失效。
  - 「⋯」菜单包含：测试连接、重命名、退出登录、删除服务器。删除服务器时会同时退出登录，并删除对应的钥匙串条目。
- **添加服务器**：在弹窗中输入框只有一个，提示文字为"服务器地址或邀请链接"。
  - 粘贴的是邀请链接：解析出服务器地址，读取 meta，兑换邀请。三步自动完成，不再弹出任何选择。
  - 粘贴的是服务器地址：读取 meta，然后进入登录弹窗。
  - 读取 meta 失败时，用直白的中文说明原因，例如"无法连接到服务器，请检查地址或网络"。
- **登录弹窗**：按 meta 中 `auth.methods` 返回的方式显示选项。
  - 「使用 GitHub 登录」：vex P2 起才有，只有 meta 返回 `github` 时才显示。点击后显示用户码和复制按钮，提供「打开 GitHub」按钮，同时显示"等待授权…"，授权完成后自动关闭。
  - 「使用邀请链接或邀请码」：一个输入框，下方说明"向服务器管理员索取；也可以在已登录的设备上执行 `vex auth invite` 生成"。
  - 错误提示要直白，例如：
    - "邀请无效或已过期，请重新索取"；
    - "尝试次数过多，请稍后再试"。
- **登录之后**：会话 token 存入钥匙串，按规范化后的服务器 URL 分条保存。客户端名称取"ruri on <电脑名>"。
- **退出登录**：先调用 `POST /v2/auth/logout`，再删除钥匙串条目。服务器连不上时也要删除本地条目，并提示"已在本机退出；服务器端会话将在过期后失效"。
- **会话失效**：收到 401 时，该服务器显示为"登录已失效"，提供「重新登录」。其他服务器不受影响。

## 服务器页与 Git 页

- 汇总所有已登录的服务器，分组层级为「服务器 → 项目 → 房间/分支」。
- 只有一台服务器且只有一个项目时，不显示分组标题。
- 每台服务器各保持一条 SSE 连接，各自独立重连。某一台断开时，只在它的分组中显示状态，不影响其他服务器。
- 房间、构建、加入操作都要同时带上服务器和项目。托管实例的标记中记录服务器 URL、项目、房间三者。

## CLI

- 服务器管理：`ruri vex servers add <地址或邀请链接> [--name]`、`ruri vex servers list`、`ruri vex servers remove <name>`、`ruri vex servers default <name>`。
- 登录相关：
  - `ruri vex login [--server <name>] [--invite <链接或码>]`。不带参数时，交互式列出可用的登录方式。
  - `ruri vex login --token-stdin`：只用于自动化，帮助文本中注明"服务账号令牌"。
  - `ruri vex logout`、`ruri vex whoami`。
- 其他命令统一接受 `--server` 和 `--project`，缺省时使用默认服务器，以及该服务器上唯一的项目或用户配置的默认项目。存在歧义时报错，并列出可选值。
- 开关关闭时，以上命令都不出现。

## 删除的内容

- 设置页中的「Vex token」输入框和「保存」按钮。
- 单一服务器地址的设置项。本轮不做旧设置迁移，原因是 R1 已经改用上游应用标识，旧数据本来就读不到。
